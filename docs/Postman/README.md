## Что внутри

Коллекция покрывает основные группы endpoint API StackScout.

Назначение коллекции:

- ручное тестирование endpoint;
- smoke-проверки после изменений backend;
- быстрое воспроизведение типовых запросов.

---

## Быстрый импорт

1. Откройте Postman.
2. Выберите Import.
3. Укажите файл `postman-collection-full-urls.json`.
4. Сохраните коллекцию в workspace.

---

## Переменные окружения

Рекомендуемый набор:

- `baseUrl`: `http://localhost:8081/api/v1`
- `token`: JWT токен (если endpoint требует авторизацию)

---

## Рекомендуемый порядок проверки

1. Проверка `health` endpoint.
2. Чтение данных (`GET` коллекции/карточки).
3. Изменяющие запросы (`POST/PUT/PATCH/DELETE`) в тестовом окружении.
4. Проверка кодов ответа и формата ошибок.

Подробные контракты endpoint описаны в [API](../API.md).
