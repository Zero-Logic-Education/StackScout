Заголовок задачи: Обновление дизайна библиотек, внедрение системы подписок и страницы обновлений.

Контекст и цель:
Необходимо провести рефакторинг и расширение функционала модуля «Библиотеки». Цель — улучшить визуальное восприятие (UX/UI), добавить механизм подписок пользователей на обновления конкретных библиотек и создать ленту обновлений.

Технические требования (Архитектура):

Reusability (Переиспользование): Используй компонентный подход (например, Atomic Design). Вынеси общие элементы (карточки библиотек, кнопки подписки, бейджи статусов) в отдельные UI-компоненты.

Extensibility (Расширяемость): Логику подписок и обновлений вынеси в кастомные хуки (например, useLibrarySubscription, useLibraryUpdates).

Type Safety: Используй TypeScript для всех интерфейсов данных (Library, Update, SubscriptionState).

State Management: Предложи оптимальный способ хранения состояния подписок (Context API или интеграция с существующим стором).

Этапы выполнения (инструкция для Агента):

Шаг 1: Планирование (Planning Mode)

Проанализируй текущую структуру папок и компонентов деталей библиотек.

Составь implementation_plan.md со схемой новых компонентов и структурой данных для подписок.

Опиши, как будет выглядеть новая страница обновлений и как она будет получать данные.

Шаг 2: Дизайн и UI

Обнови дизайн страницы деталей библиотеки (LibraryDetail): добавь акцент на основные метаданные и кнопку «Subscribe».

Создай новую страницу LibraryUpdatesPage, которая отображает хронологический список изменений в библиотеках, на которые подписан пользователь.

Используй современные CSS-паттерны (Tailwind/Styled Components) для обеспечения адаптивности.

Шаг 3: Функционал подписок

Реализуй логику: при нажатии на «Subscribe», ID библиотеки добавляется в профиль пользователя.

Добавь визуальную индикацию подписки (изменение состояния кнопки, уведомления).

Шаг 4: Верификация

Создай артефакты: скриншоты обновленного дизайна.

Проверь работу подписок в браузере (Antigravity Browser), убедившись, что состояние сохраняется при переключении страниц.

Напиши базовые модульные тесты для хуков логики.
