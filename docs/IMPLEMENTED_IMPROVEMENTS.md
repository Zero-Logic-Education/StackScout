### 📝 Примечания

1. **Backend зависимости**: Убедитесь, что backend поддерживает:
   - `GET /api/v1/libraries/{id}` - детальная информация
   - `GET /api/v1/libraries/{id}/health` - метрики здоровья
   - Пагинация в `GET /api/v1/libraries?page=X&size=Y`

2. **date-fns/locale**: Используется русская локализация для дат

3. **Навигация**: Все переходы используют Next.js router для клиентской навигации

4. **Тестирование**: Протестируйте с реальными данными от backend API

### ⚠️ Известные особенности

1. Frontend запускается на порту 3001 (если 3000 занят)
2. Требуется запущенный backend на `http://localhost:8081`
3. Метрики здоровья загружаются параллельно с основной информацией
4. При ошибке загрузки метрик - показывается toast, но страница работает
