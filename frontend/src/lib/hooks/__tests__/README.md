## Назначение

Документ описывает только тесты хуков в каталоге `frontend/src/lib/hooks/__tests__/`.

Глобальные команды frontend и CI-сценарии описаны в `frontend/README.md` и корневом README.

---

## Что тестируется

- корректность загрузки данных;
- обработка ошибок и состояний загрузки;
- сценарии подписки и отписки;
- граничные случаи с пустыми и некорректными данными.

---

## Как запускать

```bash
cd frontend
pnpm test
```

Для локальной отладки используйте запуск конкретных тестовых файлов через test runner проекта.

---

## Требования к новым тестам

- каждый тест явно описывает ожидаемое поведение;
- моки данных минимальны и читаемы;
- тесты не зависят от внешней сети;
- регрессионный баг фиксируется отдельным тест-кейсом.
